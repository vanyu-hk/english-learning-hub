### 词汇

本日共 11 条词汇记录，涵盖 12 个学习项。

| 学习项 | 核心含义与辨析 | 常见搭配 |
| --- | --- | --- |
| **basement** | 完全或部分位于地面以下的楼层或房间。**cellar** 尤其常指储藏用的地窖。 | `in the basement`, `basement flat`, `flooded basement` |
| **have a row with** | 英式口语，指与某人激烈争吵。这里 **row** 读 /raʊ/，表示一排时读 /rəʊ/（英）或 /roʊ/（美）。**have an argument with** 语气更中性，**fall out with** 强调关系闹僵。 | `have a row with someone over something`, `get into a row`, `a heated row` |
| **guilty** | 可指法律上的有罪，也可指内疚。**ashamed** 更侧重羞耻感。词族有 **guilt**、**guilty** 和 **guiltily**。 | `be found guilty of a crime`, `feel guilty about something`, `plead guilty`, `a guilty conscience` |
| **fridge / freezer** | **fridge** 冷藏，**freezer** 冷冻。**frozen** 描述已冷冻的状态，**freezing** 可描述正在冻结或非常寒冷。**refrigerator** 是 **fridge** 的完整形式。 | `keep something in the fridge`, `freezer compartment`, `frozen food`, `defrost the freezer` |
| **fortnight** | 两周，即 14 天。常用于英式英语。**in a fortnight** 表示两周后，**for a fortnight** 表示持续两周。 | `a fortnight ago`, `once a fortnight`, `a fortnightly meeting` |
| **folk** | 可指人们或某个群体。口语 **my folks** 常指父母或家人。作修饰语时常指民间传统。 | `local folk`, `folk music`, `folk art`, `folk tale`, `folklore` |
| **foal** | 幼马，也可作动词表示产下幼马。**colt** 是年轻公马，**filly** 是年轻母马，**pony** 指小型马。 | `a newborn foal`, `mare and foal`, `give birth to a foal`, `foaling season` |
| **flight** | 可指航程或航班，**plane / aircraft** 指飞机本身。还可表示飞行或逃离。**a flight of stairs** 指一段连续的台阶。 | `catch / miss a flight`, `book a flight`, `a connecting flight`, `on a flight`, `take flight` |
| **expect** | 表示预期某事会发生，或认为某人理应做某事。**wait for** 表示等待。词族有 **expectation** 和 **unexpected**。 | `expect to do something`, `expect someone to do something`, `expect that …`, `be expected to …`, `contrary to expectations` |
| **excellent** | 表示非常好或水准很高。**excellent at** 指擅长，**excellent for** 指适合。词族有 **excel** 和 **excellence**。 | `excellent condition`, `excellent performance`, `an excellent command of English` |
| **entrance** | 名词指入口或进入的动作，读 /ˈentrəns/。动词表示使着迷，重音在第二音节。 | `the main entrance`, `the entrance to the building`, `entrance fee`, `entrance exam`, `make a dramatic entrance` |

#### IELTS 要点

- **听力与口语**。听到 `have a row with` 时根据语境识别争吵义，听到 `in a fortnight` 时换算成两周后。住宿和地图场景留意 `basement level` 与 `main entrance`，旅行场景区分航班与飞机。
- **写作语域**。争端话题可用 `disagreement` 或 `dispute`。社区话题可按语境选 `residents` 或 `communities`，文化话题可保留 `folk music` 等固定搭配。正式语境中可用 `two weeks` 和 `refrigerator`。
- **写作搭配**。用 `be expected to` 描述预期变化或职责，用 `be found guilty of` 描述判决。评价时可按所指选 `high-quality` 或 `highly effective`。交通话题可用 `short-haul flights` 或 `aviation emissions`，动物话题可用 `a young horse` 解释 `foal`。

#### 易反复出错的用法

- **介词**。地点用 `in the basement`、`in the fridge / freezer`，乘机用 `on a flight`，建筑入口用 `the entrance to the building`。争吵对象用 `with`，争吵缘由用 `about / over`。罪名用 `guilty of`，内疚缘由可用 `feel guilty about / for`。
- **句型**。预期某事用 `expect something`，等待某事用 `wait for something`。把 `very excellent` 改成 `excellent`，按具体含义选 `excellent at` 或 `excellent for`。
- **拼写、发音和用词**。记住 `fridge` 里的 `d`、`folk` 中不发音的 `l`，以及两个 `row` 的读音。表示一个人时用 `a person`。用年龄辨认 `foal`，用体型类别辨认 `pony`。

#### 学习词汇、核心辨析与搭配

| 学习项 | 含义与关键辨析 | 常见搭配 |
| --- | --- | --- |
| **routine; at least** | routine 是反复执行的日常流程；regular 强调频率或规律性。at least 表示下限。 | `have / follow / establish / stick to a routine`, `daily / morning / bedtime routine`, `at least half an hour` |
| **revise / revision** | 英式 revise 可指备考复习，美式通常用 review；修改文稿的 revise 两种英语都用。 | `revise for an exam`, `revise a unit / draft / plan / estimate`, `review for an exam` |
| **aloud / silently** | aloud 是出声地，silently 是无声地；repeat to yourself 本身强调对自己重复，是否出声需看语境。 | `say / read a word aloud`, `repeat a word silently in your head`, `repeat something to yourself` |
| **write down; mark / highlight; rub out; look up** | 记录、标记／高亮、擦掉、查找。可分短语动词中的代词放中间。 | `write it down`, `rub it out`, `look it up in the dictionary`, `mark / highlight a word` |
| **cover; test yourself; check; come back to; word partner** | 主动回忆流程：先遮住释义，再自测，需要时核对，稍后再测；word partner 提醒按搭配学习。 | `cover the meaning`, `test yourself`, `check the meaning`, `come back to the word later` |
| **synonym; opposite; bilingual dictionary; dirty / filthy** | synonym 同义词，opposite 反义词；bilingual dictionary 双语词典。filthy 比 dirty 程度强，表示非常脏。 | `look up a word in a bilingual dictionary`, `a dirty / filthy room` |
| **tidy / clean; mess / messy / untidy** | tidy 指整齐，clean 指无污垢；房间可以干净但凌乱。mess 是名词，messy、untidy 是形容词。 | `a tidy room`, `clean but untidy`, `My room is messy.`, `a mess` |
| **advice / advise; argue / argument; choice / choose** | 区分名词和动词，选对词族后还要检查动词时态及主谓一致。 | `advised`（yesterday）, `advises`（习惯性现在）, `an argument`, `can choose` |
| **expand / expansion; expend** | expand 扩大，expend 较正式，指耗费时间、精力或资源。 | `expand your vocabulary`, `expend time / effort / energy` |
| **different / difference / differ; communicate / communication / communicative** | 依次注意形容词、名词、动词的语法位置；单数 usage 作主语时用 differs。 | `the difference`, `usage differs`, `good communication` |
| **permanent / temporary; kind / unkind / cruel** | 永久／暂时；友善／不友善／残忍。strict 是严格，不能直接当作 kind 的反义词。 | `a permanent / temporary job`, `be kind / cruel to animals`, `a strict teacher` |
| **soft / hard; smooth / rough; entrance / exit** | 软／硬、光滑／粗糙、入口／出口。smooth 不是“胃”，胃是 stomach。 | `a smooth / rough surface`, `the entrance / exit` |
| **dead / alive; live / living; accept / refuse / decline** | 描述活着用 `The bird is alive`，不能直接换成 live；live、living 的使用位置需结合语境。accept / refuse 可用于邀请；decline 更礼貌正式。 | `The bird is alive.`, `accept / refuse / decline an invitation` |

#### 学习过程与掌握变化

- **已纠正并回忆成功**：aloud / silently、write it down、rub it out、look it up；routine 拼写与 at least 的位置；messy 的词性；advised、advises、differs、communication；cruel 最后延迟默写正确。
- **有进步，仍需迁移检验**：主动复习顺序从两次错误（ACDB、DCAB）进步到逻辑正确，但最后一步说成 `after back to test`；应说 `come back to the word later and test yourself again`。expand 在混合测验中答对，仍应与 expend 对照复习。
- **首要薄弱项**：permanent 先写成 `perement`，延迟重测仍写成 `pemenent`，尚未掌握拼写。temporary、rough、alive 在解释后重测正确，尚需次日独立提取。

#### IELTS 要点

- **口语**：用 daily routine 描述学习习惯，组合 `spend time doing`、`at least`、`say the words aloud`。用 tidy / clean 准确描述住房，避免把“严格”误说为“不友善”。
- **写作与填空**：注意 advice / advise、difference / differ 等词性转换，以及 advises / advised / differs 的词形；用 expand your vocabulary 表达扩大词汇量。
- **听读与表达准确性**：熟悉英式 revise 的复习义；区分 permanent / temporary、entrance / exit、accept / refuse，按上下文识别反义和同义替换。以上为当日内容的应试提炼，并非 IELTS 模考成绩。

#### 反复错误与纠正

- **时间表达与句型反复不稳**：`I learn English cast a half hour` → `I spend at least half an hour learning English.`；`learning about 30 minutes` → `spend about 30 minutes studying`；`revise 10 minutes` → `revise for 10 minutes`。备考对象用 `revise for an exam`，复习内容可直接用 `revise this unit`。
- **句子完整性**：`I learning ...` → `My plan is to study ...`；两个完整句不可只用逗号连接。示例：`I spend at least half an hour learning English. This is part of my daily routine.`
- **拼写与近形词**：重点 permanent；保留 cruel 的延迟回忆成功记录，复查 routine、expand / expend。`rub is out` 已改成 `rub it out`。
- **词性与词形**：mess / messy、advice / advise，以及动词第三人称和过去式需同时判断，不能只选对词根。
